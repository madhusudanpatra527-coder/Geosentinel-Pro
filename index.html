About GeoSentinel Pro

Built for the field engineer

GeoSentinel Pro was conceived from a straightforward engineering question: "Is the ground still safe to build on, right now — and what should I do if it isn't?"

It answers that in real time, without requiring any cloud backend, proprietary hardware, or specialist software. Every calculation, recommendation, and compliance check runs directly in your browser.

Zero infrastructure required

The entire platform — including the geotechnical AI engine, siren alarm system, and compliance matrix — runs as static files. One GitHub Pages deploy, zero servers.

Fully offline — PWA installable

After the first load, a Service Worker caches the entire app shell. The dashboard works without any network connection. Install it on mobile or desktop like a native app.

Modular, open-source architecture

12 separate JS modules, each independently testable. MIT licensed. Swap in your own MQTT sensor feed and the entire platform adapts — no code changes needed in the dashboard layer.

Mission & Vision

Why we built this

Geotechnical failures cost lives. The tools to prevent them shouldn't be locked behind expensive enterprise software.

Our Mission

To democratize geotechnical monitoring by delivering a professional-grade, internationally compliant soil and foundation integrity platform that runs entirely in a web browser — free, open-source, and accessible to every engineer on the planet.

Make real-time bearing capacity monitoring accessible without proprietary hardware
Embed IS, Eurocode, and ASCE compliance checks directly into the monitoring workflow
Reduce time-to-alarm for critical foundation failures from hours to seconds
Provide evidence-based remedial recommendations at the point of detection

Our Vision

A world where every construction site — from a village school in Odisha to a high-rise in Mumbai — has access to the same quality of geotechnical intelligence that today exists only in large-scale infrastructure projects backed by expensive specialists.

Background

I'm Madhusudan Patra — a Civil Engineering student at VSSUT Burla, originally from Odisha, India. I built GeoSentinel Pro to address a real gap I observed in geotechnical practice: site engineers in India often have access to sensor data but not to the analytical tools and standards knowledge needed to interpret it quickly and safely.

This project combines my interests in structural engineering, IoT systems, and web development — and proves that a professional-grade geotechnical monitoring platform doesn't require proprietary software or an enterprise budget. It runs entirely in a browser tab.

Professional Disclaimer

Please read before using this platform for engineering decisions

Demonstration platform

GeoSentinel Pro is a prototype demonstration platform. The sensor data displayed is simulated and does not represent real geotechnical measurements from any actual construction site.

Qualified engineer required

All real-world foundation and site safety decisions must be made by a licensed geotechnical or structural engineer registered under applicable national professional bodies (e.g. INAE, ICE, ASCE).

Standards compliance caveat

The compliance matrix reflects calculations based on simulated data. Actual compliance with IS 6403, IS 1904, Eurocode 7, or any other referenced standard requires physical testing and professional certification per IS 1888:1982.

Alarm system limitations

The audible alarm system is a software simulation. It must not be used as a substitute for a certified safety instrumented system (SIS) compliant with IEC 61511 in any real safety-critical installation.

AI engine accuracy

The offline AI engine provides responses based on geotechnical theory and standard formulas. Results are for educational and preliminary assessment purposes only. The prediction tool uses simplified Terzaghi assumptions for strip footings.

Open source — no warranty

Released under the MIT License. Provided "as is" without warranty of any kind. The developer and contributors accept no liability for any damages arising from the use of this software in any capacity.

In an actual geotechnical emergency: evacuate the affected zone immediately, restrict all structural and equipment loads, contact a licensed geotechnical engineer within 24 hours, and follow the emergency protocols defined in IS 13827:1993 and your applicable national safety regulations. GeoSentinel Pro can assist with situational awareness — it cannot replace professional engineering judgment.
